# Skin Care Product Recommendation System

## Project Overview

This project uses Artificial Intelligence, Machine Learning, and Deep Learning techniques to classify skin types, detect skin diseases, and recommend suitable skincare products based on user skin conditions.

## Features

- Skin Type Classification
- Skin Disease Detection
- Personalized Product Recommendation
- Deep Learning-based Image Analysis
- User Registration and Login
- Recommendation Dashboard

## Technologies Used

- Python
- Anaconda
- TensorFlow
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- OpenCV
- Flask

## Deep Learning Models

- CNN
- ResNet50
- InceptionV3
- DenseNet201
- Xception
- YOLO

## Project Workflow

1. User Uploads Skin Image
2. Image Preprocessing
3. Skin Type Classification
4. Disease Detection
5. Product Recommendation
6. Display Results

## Future Scope

- AR-Based Skin Visualization
- Smart Mirror Integration
- Real-Time Skin Monitoring
